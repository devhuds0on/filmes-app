# Catálogo de Filmes

Aplicação React com Vite que usa React Router para navegar entre páginas
e o Supabase para consultar uma tabela de filmes.

## Páginas

| Página   | Rota             | Descrição                                   |
| -------- | ---------------- | ------------------------------------------- |
| Início   | `/`              | Apresenta a aplicação e permite a navegação |
| Listagem | `/registros`     | Lista os filmes armazenados no Supabase     |
| Detalhes | `/registros/:id` | Mostra os dados de um filme específico      |

## Tecnologias

- React e Vite
- React Router (`BrowserRouter`, `Routes`, `Route`, `Link`, `useParams`)
- Supabase Client (`@supabase/supabase-js`)
